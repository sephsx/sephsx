### What I build

Most web developers have never talked to a PLC. Most embedded engineers don't ship polished UI. I work in the space between — reading Modbus registers off industrial sensors and surfacing those values in React dashboards, end to end.

- **IoT/OT systems** — Modbus RTU polling bridges, LoRaWAN/ChirpStack integrations, serial device communication, time-series pipelines into InfluxDB
- **Real-time web** — WebSocket-driven dashboards, live data feeds, event-driven back-ends with Node.js
- **Full-stack web apps** — Laravel + Livewire + Alpine.js for reactive server-side apps; React for client-heavy dashboards
